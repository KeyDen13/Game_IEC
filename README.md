# 🎮 Juego de Símbolos Eléctricos

Juego educativo interactivo para aprender y practicar símbolos eléctricos mediante arrastrar y soltar.

## 👨‍💻 Autor

**Ken Angel Ramos Arapa**

## 📝 Descripción

Este proyecto es un juego educativo que permite a los estudiantes aprender símbolos eléctricos de una manera interactiva y divertida. El juego consiste en arrastrar imágenes de símbolos eléctricos hasta sus nombres correspondientes.

## 🎯 Características

- ✅ 3 juegos diferentes con distintos niveles de dificultad
- ⏱️ Temporizador de 1 minuto por juego
- 🖱️ Sistema de arrastrar y soltar (drag and drop)
- 📊 Resultados inmediatos con puntuación
- 🎨 Interfaz moderna y responsive
- 🔄 Mezcla aleatoria de elementos en cada partida
- 📱 Compatible con dispositivos móviles

## 🎮 Los 3 Juegos

### Juego 1: Símbolos Básicos (9 símbolos)
- Bobina
- Interruptor de posición
- Interruptor giratorio
- Parada de emergencia
- Lámpara
- Pulsador NA
- Sirena
- Temporizadores
- Y más...

### Juego 2: Contactos y Detectores (8 símbolos)
- Contactos especiales
- Detectores capacitivos
- Detectores inductivos
- Finales de carrera
- Interruptores varios

### Juego 3: Protección Eléctrica (5 símbolos)
- Fusibles
- Interruptores diferenciales
- Magnetotérmicos
- Térmicos
- Protecciones especiales

## 🚀 Cómo Jugar

1. Selecciona uno de los 3 juegos del menú principal
2. Haz clic en "INICIAR JUEGO"
3. Arrastra cada imagen hasta su nombre correspondiente
4. Tienes 1 minuto para completar todos los emparejamientos
5. Presiona "CONFIRMAR" cuando hayas terminado
6. ¡Revisa tu puntuación!

## 🛠️ Tecnologías Utilizadas

- HTML5
- CSS3 (con animaciones y diseño responsive)
- JavaScript (vanilla, sin frameworks)
- API de Drag and Drop de HTML5
